    Acerca de este tablero

    • Todos los datos son sintéticos: un simulador hidráulico genera 14 días de SCADA a 1 segundo para un ducto ficticio. No representa ninguna operación ni producto real.
    • El día 0 es de comisionamiento: con él se calibran la fricción del gemelo, el sesgo de los caudalímetros y los umbrales de detección.
    • El modelo es cuasi-estacionario con retardos de onda: no reproduce reflexiones ni flujo parcial. El factor de emisión es referencial.
    • Código, supuestos y tablas para Power BI en github.com/johnmoya/slurry-pipeline-monitor.
